# Underwater Photography Workflow Tool (WIP)  

📸 A macOS app designed to streamline the daily workflow of an underwater photographer.  
This tool helps automate the process of organizing customer-selected photos, making it easier and more efficient to manage photo sales and folder creation.  

## Features (Current)  
- **Photo Selection Parsing**: Parse a list of photo names/numbers provided by customers.  
- **Folder Automation**: Automatically create customer folders and copy the selected photos into them.  

## Planned Improvements  
- Expand features to simplify daily tasks for underwater photographers.  
- Integrate additional tools to improve efficiency, such as batch editing, tagging, and archiving.  
- Enhance the user interface and provide seamless photo management.  

## Technical Details  
- Built with **Swift** and **SwiftUI**.  
- Uses **The Composable Architecture (TCA)** for experimenting with a modular, testable architecture.  

## Why This Tool?  
As an underwater photographer, I often sell photos directly to customers. This involves manually selecting photos based on a list they provide and organizing them into folders—a repetitive and time-consuming task. This app automates much of that process, saving time and reducing errors.  

## Status
